# One Click, One Block

One Click, One Block is a super simple mod that makes one click break one block. With a fast enough tool, like an Efficiency V shovel on dirt or a pickaxe with Haste on stone, blocks break so quickly that a single click often takes out two or three. With this mod, a click breaks exactly one, and holding the button still mines in a row as usual.

It's client-side, so it works on any server.

### Requirements

Only Fabric Loader. It doesn't need Fabric API.

### Compatibility

It runs on Minecraft 26.3 with Fabric. Install it on your client. It isn't needed on the server.

### How to use

- Click a block to break it. Click again to break the next one.
- Hold the button to keep mining. After the first block there's a pause of a tenth of a second, then blocks break one after another as they normally would.
- It only changes blocks that break instantly. Slower mining, and creative, work as in vanilla.
- There are no settings.
